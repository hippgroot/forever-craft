# Forever Craft

A Fabric modpack for the Forever Craft server.

**Minecraft 26.3** · **Fabric Loader 0.20.1** · 61 mods, 11 resource packs, 3 shader packs. See the [full mod list](MODLIST.md).

The pack keeps itself up to date. Once it's set up, every launch checks this repo and downloads
whatever changed, so you always match the server.
